# issue-tracker — Wafer Wizards

An equipment maintenance and issue tracker, organized around equipment and its failure history rather than around tickets.

A complete re-write in Next.js with PostgreSQL, replacing an earlier MERN build on Create React App. Queries are raw SQL against a relational schema; authentication is NextAuth with hashed credentials and middleware-enforced session checks.

The progress can be viewed at [the website](https://wafer-wizards.vercel.app/) on Vercel.
